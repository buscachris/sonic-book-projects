# Sonic book projects

- Give each book its own directory under `books/` and each chapter its own
  self-contained project directory. Do not share mutable scene assets across
  chapters; later lessons must leave earlier examples usable.
- Every chapter MUST include `README.md`: explain the chapter in original
  words, the Sonic-inspired interpretation, the chosen approach and why,
  differences from the book, exact tools used, open/rebuild instructions,
  checks actually performed, and limitations. Use `templates/CHAPTER_README.md`.
- Keep original editable Blender files, source scripts, Unity exports,
  previews, and relevant validation evidence together with their chapter.
- Record actual installed/tested versions. Do not claim compatibility,
  gameplay, screenshots, or tests that were not observed.
- Use original geometry, materials, and code. Do not copy book prose,
  screenshots, code bundles, ROMs, ripped assets, music, or credentials here.
- Keep Unity `.meta` files and package locks. Ignore Unity caches and Blender
  recovery copies. Do not disable the user's global Blender backups.
- Inspect existing files before editing. This collection is independent of
  the Scourge ROM workspace; do not modify or launch ROM projects here.
